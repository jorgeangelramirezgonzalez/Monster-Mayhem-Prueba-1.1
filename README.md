# Monster Mayhem - Hexagonal Grid Test

## 📝 Project Description
This is the initial prototype for the "Monster Mayhem" board game. It features a fully dynamic, client-side 10x10 hexagonal grid where players can interact with the tiles and spawn units.

## 🚀 Features Implemented
* **Dynamic Grid:** 100 regular hexagons generated via JavaScript loops.
* **Perfect Alignment:** Custom CSS layout handling row offsets to eliminate gaps between hexagons.
* **Hover Effect:** Visual feedback (teal highlight) when hovering over any tile.
* **Selection Logic:** Click interaction to select a single tile (gold highlight) with mutual exclusivity (only one active tile at a time).
* **Monster Spawning:** A UI button to spawn a monster token (`👾`) inside the selected hexagon with a smooth pop-in animation.

## 🛠️ Technologies Used
* HTML5
* CSS3 (Clip-path, Keyframes, Nth-child selectors)
* JavaScript (Vanilla ES6)

## 📌 How to Run the Project
1. Clone the repository.
2. Open `index.html` in any modern web browser (or use the VS Code Live Server extension).
